# SuperHub 的注意力设计

SuperHub 把交办、执行和回报串在一起，让你知道事情在哪里推进，也能自己决定何时回来查看。

- **交办有落点。** 接口人把目标和边界交到对应工作区，回执保留进入原工单的入口。
- **过程有归属。** 一个项目的对话、材料、决定和成果留在对应工作区。你可以在另一项工作里继续自己的主线。
- **回来有线索。** 红点提示接口人有未读内容。打开汇报先看到结论和待确认项，需要追溯时回到原工单。「今天」集中呈现项目和交付。

这套设计借鉴了以下研究。文献用于说明产品设计动机。

- Sophie Leroy（2009）讨论任务切换时的注意力残留。 [Why is it so hard to do my work?](https://doi.org/10.1016/j.obhdp.2009.04.002)
- Erik M. Altmann 与 J. Gregory Trafton（2002）讨论如何通过线索重新提取任务目标。 [Memory for goals: An activation-based model](https://doi.org/10.1207/s15516709cog2601_2)
- Mica R. Endsley（1995）用感知、理解与预判来描述局势感知。 [Toward a Theory of Situation Awareness in Dynamic Systems](https://doi.org/10.1518/001872095779049543)
